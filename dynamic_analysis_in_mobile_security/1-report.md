Objective

The objective was to identify and extract the decrypted flag generated by the native library libnative-lib.so through the JNI method Java_com_example_app_Native_getSecretMessage.

Key Findings
Target Library: libnative-lib.so
Target JNI Function: Java_com_example_app_Native_getSecretMessage
Return Type: jstring
Extracted Flag: FLAG{jn1_n4t1v3_h00k_succ3ss_2026}
Methodology

1. Function Identification
Frida was used to dynamically locate the JNI function with Module.findExportByName(). This allowed the function address to be resolved at runtime without relying on fixed or hardcoded memory offsets.

2. Runtime Hooking
An Interceptor.attach() hook was placed on the identified function to monitor its execution and capture the returned value.

3. Decrypted String Extraction
During the onLeave callback, the returned jstring handle was processed through the JNI environment using Java.vm.getEnv().getStringUtfChars(). This made it possible to obtain the decrypted string directly from memory at runtime.

4. Result
The decrypted flag was successfully captured from the native function's return value before the temporary string reference was released.
